# Pixie test site

A tiny one-page site used to test Pixie handing steps to Claude Code.

## What's here

- `index.html`: one page that says "Hello from Pixie" in hot pink (`#ff69b4`) on a dark background (`#121212`), with a small About section below the heading explaining what the site is for.

## Viewing it

Open `index.html` in any web browser. There's no build step and nothing to install.
